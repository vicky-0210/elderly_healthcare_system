# NVIDIA Jetson Nano

Validate exported operators, numerical precision, per-signal preprocessing parity, batch-one latency, RAM, power/thermal behavior and concurrent execution of all four modules. Do not assume support for a precision or accelerator feature merely because another Jetson model supports it.
