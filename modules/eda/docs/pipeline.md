# Training and replay entry points

Follow the [EDA runbook](../README.md) for executable commands and the [study protocol](../../../research/wesad_research_protocol.md) for the statistical design. Source extraction reads synchronized pickles and checks native device headers. Signal preparation is continuous and subject-local. Tensor and feature windows carry subject ID and start/end seconds in a separate metadata array.

The two model families consume the same subject partitions. Their catalogues are the executable experiment definitions. JSON files in `configs/` describe the study defaults and the controlled comparison manifest. Development split, normalization, tuning and classification metadata are recorded for each fold. The portable [model comparison](../../../research/results/wesad_loso_v1/README.md) separates fixed configurations from selection inside LOSO.

`wearable_eda.inference.predictor.EDAPredictor` accepts a synchronized recording prefix. Call `load(export_directory)` once, then `predict(payload)` after completing each observation window. Supply a common `clock_domain`, `stream_id` and a `streams` dictionary keyed by the required modalities in the export. Each stream has `samples`, `timestamps` in seconds and `unit`. EDA uses µS (unit string `uS`), motion uses time-major three-axis g, temperature uses °C (`degC`) and BVP uses the native E4 scale. Arrays begin at the common session origin. The adapter validates alignment, converts acceleration g to the research transform's E4 units, and emits the most recent 60-second score. File replay is the reference implementation. Prefix computation cost grows with session length.

An invalid observation returns `insufficient_signal` and null scores. The training metrics use the prespecified dataset eligibility rule. The runtime additionally abstains for unusable contact, flat EDA, irregular timestamps or missing auxiliary streams. Its field coverage and alert burden require a separate device study. Model size and desktop timings are measured independently of the 60 s needed to observe the participant.

For a rest-calibrated export, supply `rest_interval_s = [start, end]` on the same session clock as the samples. An operator must designate exactly 120 s of resting capture on quarter-second boundaries. The interval must end before the first scored sample and contain adequate usable EDA. In the zero-calibration exports, the adapter uses absolute features with frozen training statistics. The portable linear export verifies every calibration and feature transformation against its research estimator before publishing the coefficients.
