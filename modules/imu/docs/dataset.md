# SisFall data contract

The reader accepts a release directory containing `Readme.txt` and subject folders, or its parent. Each file has one nominal 200 Hz sample per semicolon-terminated row. Its basename is activity_subject_trial. SA identifies a younger adult and SE an older participant. Labels D01–D19 and F01–F15 apply to whole recordings. The loader retains all subject, activity and trial IDs in the derived manifest.

Read all nine signed native columns. Use ADXL345 columns 1–3 at 32/8192 g per count and ITG3200 columns 4–6 at 4000/65536 degrees/s per count as specified by the local release. Columns 7–9 belong to the MMA8451Q. Each participant folder, filename, exact count encoding, duplicate signal fingerprint and sample width are checked. Equal successive readings and rails are flagged and retained. Elapsed times come from sample indices and the nominal rate. Original timestamps and precise impact markers are unavailable.

The local audit includes 4,500 out of 4,505 files. Five filenames in SA15 identify SE15 and conflict with independently present SE15 files. See the [audit](../../../research/results/sisfall_v1/dataset_audit.json) and [per-activity breakdown](../../../research/results/sisfall_v1/activity_audit.csv). For the local dataset keep `data/imu/processed/sisfall_v1/manifest.csv` and `research/results/sisfall_v1/excluded.csv` with the run artifacts. Only SE06 among 15 older subjects contributed falls.
