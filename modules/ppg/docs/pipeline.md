# OSASUD pipeline

The offline entry points reconstruct patient packets, derive gap-aware pulse and respiratory features, train hierarchical event and subtype heads, and score held-out patients. The streaming predictor shares the optical frontend, loads the model's normalization and calibration from the export, and reports the time at which each score became available. The module README gives the runnable sequence and artifact locations.
